

# MindCows

Bienvenidos a **MindCows**, un juego divertido e interactivo desarrollado para la [Supabase Hackathon Launch Week 12, 2024](https://supabase.com/blog/supabase-lw12-hackathon). Este proyecto fue creado con **Flutter** y **Supabase** y es completamente de código abierto.

## Descripción general

**MindCows** es un emocionante juego de puzzles multijugador en el que los jugadores ponen a prueba sus habilidades cognitivas adivinando los números exactos en cada posición de los tableros de sus oponentes. El juego aprovecha **Supabase** para las capacidades multijugador en tiempo real, el almacenamiento de datos y la autenticación, mientras que **Flutter** proporciona una experiencia de usuario fluida y multiplataforma.

## Características

- **Multiplataforma**: Disponible tanto para iOS como para Android, ofreciendo una experiencia consistente en todos los dispositivos.
- **Soporte multijugador en tiempo real**: Juega con amigos y otros jugadores en tiempo real, habilitado por la API en tiempo real de Supabase.
- **Autenticación de usuarios**: Inicio de sesión seguro y gestión de perfiles impulsados por Supabase Auth, garantizando la seguridad de los jugadores.
- **Tabla de clasificación global**: Compite con otros y sigue tu posición en el ranking.
- **Almacenamiento de datos**: El progreso del juego y las estadísticas de los jugadores se almacenan de forma segura utilizando la base de datos PostgreSQL de Supabase.
- **Arquitectura escalable**: Diseñado para escalar sin problemas a miles de millones de usuarios utilizando la robusta infraestructura de Supabase.
